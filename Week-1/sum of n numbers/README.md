## Program: Sum of n Numbers

### Description

This program calculates the sum of first n natural numbers using an iterative approach.

### Input

A single integer n

### Output

Sum of first n natural numbers

### Time Complexity

T(n) = O(n)

### Methodology

* The sum is calculated using a loop from 1 to n.
* Execution time is measured for different values of n.
* A graph is plotted using Python to analyze time complexity.

### Observation

The graph shows linear growth, confirming the time complexity O(n).
