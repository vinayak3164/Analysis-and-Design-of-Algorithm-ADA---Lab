

## Program: Selection Sort

### Description

This program implements the Selection Sort algorithm to sort an array of elements.

### Input

Array of integers of size n

### Output

Sorted array in ascending order

### Time Complexity

T(n) = O(n²)

### Methodology

* The algorithm is implemented using C++.
* The program runs for different input sizes (n).
* Execution time is recorded using the chrono library.
* A graph is plotted using Python to compare actual time with theoretical O(n²).
