## Program: Power of a^b

### Description

This program computes a raised to the power b using recursion and divide & conquer approach.

### Input

Two integers: a (base), b (exponent)

### Output

Value of a^b

### Time Complexity

* Recursive: O(b)
* Optimized (Divide & Conquer): O(log b)

### Methodology

* The algorithm is implemented using recursion.
* A faster method using divide and conquer is also implemented.
* The number of operations is reduced by splitting the exponent.

### Observation

The optimized approach is significantly faster than the simple recursive method.
