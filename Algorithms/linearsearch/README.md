## Program: Linear Search

### Description

This program implements Linear Search to find an element in an array.

### Input

* Array of integers
* Element to search

### Output

Index of element if found, otherwise -1

### Time Complexity

T(n) = O(n)

### Methodology

* The array is traversed sequentially from beginning to end.
* The key is compared with each element.
* Execution time is measured for different input sizes.
* A graph is plotted using Python to analyze time complexity.
